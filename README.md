# Hexterra

Juego original de estrategia y conquista por turnos para jugar con amigos desde el navegador.

**Jugar:** https://santiagodibella2020.github.io/hexterra/

- Salas online: creás una sala y mandás el link (`?sala=CODIGO`). Quien crea la sala tiene que dejar el juego abierto mientras juegan (las conexiones son directas entre navegadores).
- Modo Blitz (10-15 min), Desafío del día con resultado para compartir, bots, alianzas y traiciones, reacciones en vivo.
- Mundo cambiante: oro, edificios, cuatro estaciones y fenómenos naturales.

Todo el juego está en `index.html`, sin dependencias para compilar.
